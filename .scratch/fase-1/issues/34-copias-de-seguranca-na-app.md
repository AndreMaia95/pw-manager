# 34: Cópias de segurança na app

**What to build:** Na app, o utilizador vê as cópias de segurança, exporta uma para um disco externo, abre uma só para leitura e restaura entradas individuais ou o cofre inteiro.

**Blocked by:** 21, 24

**Status:** ready-for-agent

- [ ] Lista de cópias de segurança com data
- [ ] Exportar uma cópia para uma pasta escolhida
- [ ] Abrir uma cópia com a palavra-passe em vigor nessa data e ver as entradas só para leitura
- [ ] Restaurar uma entrada ou o cofre inteiro, com confirmação
