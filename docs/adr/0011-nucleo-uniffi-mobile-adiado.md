# Núcleo Rust com API compatível com UniFFI; decisão iPhone/Android adiada

A fase 1 é só desktop. A escolha entre iPhone (Apple Developer Program, 99 USD/ano, obrigatório para a extensão de preenchimento; nenhuma via da UE o evita) e Android (preenchimento gratuito com instalação própria) fica para a fase mobile. Para não fechar portas, a API do vault-core é desenhada desde já para ser exposta via UniFFI a Swift e Kotlin, não apenas aos comandos do Tauri.
